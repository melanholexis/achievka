# Ачивка

Локальное Windows-приложение для учёта выполненных заданий, опыта и достижений. Встроенный курс «Python с нуля» можно открыть из меню Ачивки. Другие курсы открываются в браузере по сохранённому адресу.

## Запуск

- Из ZIP на GitHub. Скачай исходники через **Code → Download ZIP** и полностью распакуй архив. Установи **JDK 17 для Windows x64**, добавь его папку `bin` в `PATH` и запусти `run.bat` из распакованной папки `achievka-main`.
- Из готового пакета. Запусти `Achievka.exe` в папке пакета. Рядом с файлом должны оставаться папки `app` и `runtime`. Отдельная установка Java не нужна.
- Для сборки пакета запусти `package.bat` в JDK 17 для Windows x64. Результат появится в `dist\windows-1.4.1\Achievka`. Для передачи на другой компьютер можно архивировать эту папку целиком.

## Демонстрация для записи

Нажми «Демонстрация» на экране входа или в боковой панели. Показ автоматически проводит по экранам Ачивки в тёмной теме на отдельном учебном профиле и работает без интернета. Для перехода к сцене нажми её сегмент на нижней шкале. Пробел ставит показ на паузу, стрелки переключают сцены, H скрывает кнопки для съёмки, Esc возвращает на прежний экран. Финальный кадр держится до повтора или выхода.

## Курсы и прогресс

1. Выбери локальный профиль или создай новый.
2. Открой встроенный курс из меню. Задания синхронизируются с профилем, указанным при открытии. Копия курса доступна и без сети.
3. Чтобы добавить свой курс, открой «Курсы» и укажи адрес страницы или `course-data.js`. Сканер также распознаёт некоторые HTML-списки заданий. Кнопка «Убрать» скрывает курс, а повторное добавление по тому же адресу данных возвращает его прогресс.

Для переноса заданий с внешнего сайта открой «Профиль и данные» → «Перенести выполненные задания с сайта». Создай закладку из скопированного кода, запусти её на странице курса в том браузере, где выполнялись задания, и вставь полученный JSON в Ачивку. Эта функция ожидает сохранение с массивом `solved` в `localStorage`. У внешнего сайта можно указать имя ключа тегом `<meta name="achievka-storage-key" content="my_course_progress">` на странице курса.

В разделе «Курсы» кнопка «Посмотреть задания» показывает уроки, отмеченные сайтом, изменения порядка и исчезнувшие уроки. Проверь отметки и нажми «Применить». Список сохраняется на компьютере. Для ручного обновления выбери «Обновить список уроков». При переходе со старой версии сверь отметки, которые были привязаны к номеру строки. Для HTML-курса устойчивость к переименованию обеспечивают постоянные data-id или ссылки у уроков.

Встроенный курс и его код поставляются в составе приложения. Для обновления встроенных упражнений установи новую версию Ачивки.

## Спутники

Во вкладке «Награды» нажми «Взять с собой». Выбранный спутник появится на экране «Мой путь». Искрик открывается за любое сданное задание и находит модуль, где осталось меньше всего шагов. Лунница появляется за половину курса и подсказывает задание с наибольшей наградой XP. Аметист открывается за весь курс и позволяет скопировать текстовую открытку с результатом.

Коллекция учитывает ранее сданные задания и импортированный прогресс. Выбор сохраняется отдельно для каждого профиля и курса и входит в резервную копию.

## Резервные копии

Во вкладке «Профиль и данные» сохрани JSON для текущего профиля. На другом ПК выбери профиль и загрузи файл там же. Резервная копия включает курсы с выполненными заданиями или сброшенным прогрессом, в том числе скрытые. Импорт объединяет задания одной версии прогресса и учитывает версию сброса. Копия версии 2 включает сохранённый список уроков и синхронизированное состояние комнаты героя, в том числе монеты, покупки и ответы. После перехода с 1.2 один раз открой встроенный курс под своим прежним профилем и дождись синхронизации комнаты перед экспортом. Копии версии 1 поддерживаются. Размер файла ограничен 64 МиБ. Ключ профиля можно скопировать отдельной кнопкой.

Данные приложения хранятся в `%USERPROFILE%\Achievka`. Для отдельного тестового профиля можно запустить `Achievka.exe "--profile=C:\папка\профиля"`.

## Проверки

Запусти `test.bat`. Он проверяет расчёт XP, локальный API, сохранение прогресса, отклонение снимков до сброса, скрытие курса, URL в подпапке и импорт копии. Интеграционные проверки используют временный профиль и локальный пример курса.

Для полного прогона требуется Node.js и графический сеанс Windows. В test.bat входят проверка четырёх учебных задач и сценарий JavaFX с предпросмотром импорта, покупками, переносом комнаты в чистый профиль, сбросом и выбором спутников.
